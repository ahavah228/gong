# 공덕교회 주차관리 앱

교인이 차량을 등록하고 예배별 주차를 신청하면, 관리자가 승인·입차를 처리하는 모바일 웹앱입니다.

- **화면**: GitHub Pages (무료 호스팅) — `index.html`, `config.js`, `demo.js`
- **데이터·서버**: Google 시트 + Apps Script — `apps-script/Code.gs`

## 주요 기능

| 교인 | 관리자 |
|---|---|
| 차량 등록 (휴대폰 번호 + PIN으로 로그인) | 날짜·예배별 신청 현황 (승인/면수, 진행률) |
| 예배일·예배·차량·구분 선택해 주차 신청 | 승인 / 반려 / 입차 / 취소 처리 (처리자 기록) |
| 내 신청 내역 확인·취소 | 차량번호 뒷자리로 차주 조회 → 바로 전화 |
| 차량 여러 대 추가·삭제 | 전화·현장 요청 대리 등록 |

구분(장애인·임산부·노약자·봉사자 등), 예배 목록, 예배별 주차면수, 자동승인 여부, 공지는 시트의 **설정** 탭에서 바로 바꿀 수 있습니다.

---

## 1단계: 구글 시트 + Apps Script (약 10분)

1. 교회 공용 구글 계정으로 [sheets.new](https://sheets.new) 에서 새 시트를 만들고 이름을 `공덕교회 주차관리`로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs` 전체를 붙여넣은 뒤 저장(💾)합니다.
4. 맨 위 `INITIAL_ADMIN_PASSWORD` 값을 관리자 비밀번호로 바꾸고 저장합니다.
5. 상단 함수 선택에서 **setup** 을 고르고 **실행** → 권한 승인 (“확인되지 않은 앱” 화면이 나오면 *고급 → 이동*).
   시트에 `교인차량`, `주차신청`, `설정` 탭이 생기면 성공입니다.
6. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙️ **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
7. **배포** 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 관리자 비밀번호 변경: Apps Script **프로젝트 설정 → 스크립트 속성 → `ADMIN_PASSWORD`** 값을 수정하세요.
> `SECRET` 속성은 절대 바꾸거나 지우지 마세요 (바꾸면 모든 교인의 PIN이 무효가 됩니다).

## 2단계: GitHub Pages 배포 (약 5분)

1. GitHub에서 새 저장소(예: `gongdeok-parking`, Public)를 만듭니다.
2. **Add file → Upload files** 로 `index.html`, `config.js`, `demo.js`, `README.md`, `apps-script` 폴더를 올립니다.
3. 저장소에서 `config.js` 를 열어 ✏️ 편집 → 복사한 URL을 붙여넣고 커밋합니다.
   ```js
   window.API_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```
4. **Settings → Pages → Branch: `main` / `(root)` → Save**
5. 1~2분 뒤 `https://<깃허브아이디>.github.io/gongdeok-parking/` 주소로 접속됩니다.

이 주소를 QR코드로 만들어 주보·주차장 안내판에 붙이거나, 단체 카톡방에 공유하세요.
휴대폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 코드 수정 후 다시 배포할 때

- **Code.gs 수정** → Apps Script **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포** (URL 그대로 유지)
- **화면 수정** → GitHub에 파일만 다시 올리면 자동 반영

## 데모 모드

`config.js`의 `API_URL`을 비워 두면 서버 없이 브라우저 안에서만 동작하는 데모가 실행됩니다.
샘플 교인: `010-1234-5678` / PIN `1111`, 관리자 비밀번호 `1234`.

## 상태 흐름

```
신청 ──승인──▶ 승인 ──입차──▶ 입차
  │  (면수 초과 시 자동승인이면 '대기')
  └──반려──▶ 반려      (교인 본인 또는 관리자가 '취소' 가능)
```

## 보안·개인정보

- PIN은 시트에 원문이 아닌 해시값으로 저장됩니다.
- 연락처 조회는 관리자 로그인 후에만 가능합니다. 시트 자체의 공유 범위는 담당자로 제한하세요.
- 등록 화면에 개인정보 수집·이용 동의가 포함되어 있습니다. 교회 방침에 맞게 문구를 조정하세요.
